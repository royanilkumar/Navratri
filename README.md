# Navratri Daily Posts (नवरात्रि दैनिक पोस्ट)

Nine daily WhatsApp posts, one for each form of Maa Durga (Navdurga), in **Hindi** and **English**.
Each post is a 2-3 minute read and is formatted with WhatsApp markup (`*bold*`, `_italic_`) so it can be copied and pasted directly.

## Structure

```
posts/
  day-01-shailputri/   hi.md  en.md
  day-02-brahmacharini/
  day-03-chandraghanta/
  day-04-kushmanda/
  day-05-skandamata/
  day-06-katyayani/
  day-07-kalaratri/
  day-08-mahagauri/
  day-09-siddhidatri/
images/                 one picture per day (see images/README.md)
SOURCES.md              scriptural sources and notes on traditions
REVIEW_CHECKLIST.md     what reviewers should check
```

## How to review

1. Read `REVIEW_CHECKLIST.md`.
2. Open an **Issue** or a **Pull Request** per day (e.g. "Day 4: Malpua bhog differs in our tradition").

## Posting

Post the day's content on the matching day of Navratri. Check your local panchang first, because tithis can shift or merge, and the form worshipped on a given date may differ by a day.
